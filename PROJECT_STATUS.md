## 🎯 1. Цель и Описание Проекта
- **Название**: Всероссийская Федерация Литрбола (ВФЛ) / `litrball-app`
- **Описание**: Интерактивное веб-приложение (Telegram Mini App), REST API и полнофункциональный Telegram-бот для сатирической аттестации, расчета спортивных разрядов по «литрболу», прохождения допинг-контроля («Детектор Пиздежа»), экзамена ВАК, проведения баттлов в группах («Застольная Заруба») и генерации официальных спортивных удостоверений («корочек») с печатью ВАК.
- **Стек технологий**:
  - **Бэкенд & Бот**: Python 3.10+, `aiogram 3.14+`, `Pillow (PIL)`, `python-dotenv`, `pytest 9.x`
  - **Веб-сервер & API**: Чистый Python 3 (`http.server` с кастомным REST API `/api/drinks`, `/api/calculate`, раздачей статики)
  - **База данных**: SQLite 3 (`litrball.db`), модуль `database.py` (с поддержкой переменной `LITRBALL_DB_PATH` для изоляции тестов)
  - **Фронтенд (Mini App)**: Vanilla JavaScript, HTML5 Canvas, адаптивный CSS3 (Mobile-first PWA / TMA)
  - **Инфраструктура & Деплой**: Docker (`Dockerfile`, `docker-compose.yml`), Render.com (`render.yaml`, Web Service 24/7), Bash-оркестрация (`start.sh`, `start_bot.sh`)
- **Репозиторий**: [github.com/Roma15228/litrball-app](https://github.com/Roma15228/litrball-app)
- **Telegram-бот**: `@gamumuFILMS_bot` (с поддержкой инлайн-режима)
- **Облачный хостинг**: Render.com (`https://litrball-federation.onrender.com`)

## 🏗️ 4. Ключевые архитектурные решения (ADR)
- **ADR-1: Zero-heavy-dependencies для WebApp**: Чистый Python 3 `http.server` для мгновенного запуска и низкого потребления RAM.
- **ADR-2: Двухпроцессный запуск через `start.sh`**: Одновременный запуск веб-сервера и бота с перехватом сигналов.
- **ADR-3: Anti-Sleep Keep-Alive Daemon**: Фоновый поток для предотвращения сна бесплатного инстанса Render.
- **ADR-4: Гибридная генерация удостоверений**: HTML5 Canvas (клиент) + Pillow (сервер).
- **ADR-5: SQLite с поддержкой переменной окружения `LITRBALL_DB_PATH`**: Позволяет изолировать тестовую базу данных от рабочей базы `litrball.db`.
- **ADR-6: Стандартизированная библиотека напитков ВФЛ**: Единый реестр пресетов (`/api/drinks`) с калорийностью, ABV и плотностью спирта 0.789 г/см³.

## ⚠️ 5. Известные проблемы и ограничения
- **Конфликт Telegram Long Polling при локальной разработке**: Боевой токен уже запущен в облаке. Для локальной разработки бота использовать dev-токен, либо запускать локально только `app.py`.
- **Эфемерный диск Render Free**: Сброс SQLite при холодном перезапуске сервиса.
