## 🎯 1. Цель и Описание Проекта
- **Название**: Всероссийская Федерация Литрбола (ВФЛ) / `litrball-app`
- **Описание**: Интерактивное веб-приложение (Telegram Mini App), REST API и полнофункциональный Telegram-бот для сатирической аттестации, расчета спортивных разрядов по «литрболу», прохождения допинг-контроля («Детектор Пиздежа»), экзамена ВАК, проведения баттлов в группах («Застольная Заруба») и генерации официальных спортивных удостоверений («корочек») с печатью ВАК.
- **Стек технологий**:
  - **Бэкенд & Бот**: Python 3.10+, `aiogram 3.14+`, `Pillow (PIL)`, `python-dotenv`
  - **Веб-сервер & API**: Чистый Python 3 (`http.server` с кастомным REST API и раздачей статики) без тяжелых сторонних фреймворков
  - **База данных**: SQLite 3 (`litrball.db`), модуль `database.py`
  - **Фронтенд (Mini App)**: Vanilla JavaScript, HTML5 Canvas, адаптивный CSS3 (Mobile-first PWA / TMA)
  - **Инфраструктура & Деплой**: Docker (`Dockerfile`, `docker-compose.yml`), Render.com (`render.yaml`, Web Service 24/7), Bash-оркестрация (`start.sh`, `start_bot.sh`)
- **Репозиторий**: [github.com/Roma15228/litrball-app](https://github.com/Roma15228/litrball-app)
- **Telegram-бот**: `@gamumuFILMS_bot` (с поддержкой инлайн-режима)
- **Облачный хостинг**: Render.com (`https://litrball-federation.onrender.com`)

## 🏗️ 4. Ключевые архитектурные решения (ADR)
- **ADR-1: Zero-heavy-dependencies для WebApp**: Сервер реализован на базе `http.server` без FastAPI/Django/Flask для мгновенного холодного старта, минимального потребления RAM (<50 МБ) и отсутствия проблем с зависимостями.
- **ADR-2: Двухпроцессный запуск через `start.sh`**: Сервер Mini App и Telegram-бот запускаются одновременно в фоновых процессах с перехватом сигналов `SIGINT`/`SIGTERM`.
- **ADR-3: Anti-Sleep Keep-Alive Daemon**: Встроенный фоновый поток в `app.py` пингует `GET /api/health` каждые 8 минут, исключая засыпание бесплатного инстанса Render.com.
- **ADR-4: Гибридная генерация удостоверений**: HTML5 Canvas для живого превью и редактирования на фронтенде + Pillow на бэкенде для гарантированной отправки ботом в высоком разрешении.
- **ADR-5: SQLite с автоинициализацией**: Модуль `database.py` автоматически создает таблицы при запуске (`init_db`), что гарантирует работоспособность приложения на чистых окружениях.

## ⚠️ 5. Известные проблемы и ограничения
- **Конфликт Telegram Long Polling при локальной разработке**: Если запустить `bot.py` локально с боевым токеном, Telegram возвращает `409 Conflict`, так как экземпляр бота уже запущен на Render. Решение: для локальной разработки бота использовать токен dev-бота от BotFather, либо запускать локально только `app.py`.
- **Эфемерный диск Render Free**: На бесплатном тарифе Render файловая система сбрасывается при холодном перезапуске контейнера (база данных и загруженные фотографии комнат обнуляются). Для долговременного хранения запланирован переход на PostgreSQL / облачный S3.
