# Синхронизация сессий и восстановление контекста

## 1. Действия при старте новой сессии (Resume Session)
Когда пользователь пишет "продолжаем", "статус", "на чём мы остановились?" или начинает работу в проекте:
1. Прочитать `PROJECT_STATUS.md`.
2. Проверить текущее состояние git: `git status -s` и `git log -n 3 --oneline`.
3. Составить краткий отчет для пользователя:
   - Что было сделано ранее.
   - Какая задача сейчас в статусе `In Progress`.
   - Что предлагается сделать прямо сейчас.

## 2. Действия перед завершением работы (Save Session)
Когда пользователь просит сохранить статус или планирует перезагрузиться / завершить сессию:
1. Обновить секцию `3. Список задач (Task Board)` в `PROJECT_STATUS.md`.
2. Добавить краткую запись в `6. Лог последних изменений`.
3. Зафиксировать изменения в git: `git add . && git commit -m "chore: update project status"`.
4. Сообщить пользователю, что состояние проекта сохранено и готово к продолжению.
