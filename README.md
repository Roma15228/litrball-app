# 🍺 Всероссийская Федерация Литрбола (ВФЛ)

Интерактивное веб-приложение и полноценный Telegram-бот для сатирической аттестации, расчета спортивных разрядов по «литрболу», прохождения допинг-контроля («Детектор Пиздежа»), сдачи экзамена ВАК и генерации персонализированных спортивных удостоверений («корочек») в высоком разрешении.

---

## 🌟 Основные возможности

### 1. 🎯 «Детектор Пиздежа» (Система проверки перед сдачей)
Чтобы спортсмены не завышали свои достижения и не занимались приписками, ВАК ввела обязательный полиграф:
- **Кассовая математика в 02:45 ночи:** расчет сдачи в круглосуточном ларьке за 10 секунд;
- **Моторный тремор рук («Поймай огурец»):** интерактивная мини-игра — поймать уворачивающийся соленый огурец 4 раза;
- **Фото-контроль тары:** загрузка снимка пустых бутылок или барного чека (ИИ-сканирование ВАК);
- **Официальный защитный штамп:** после проверки на корочку ставится оттиск: `★ ПРОВЕРЕНО ВАК: ПИЗДЕЖА НЕТ ★`.

### 2. 🧮 Калькулятор спортивного норматива (ЕЗСК)
- Ввод веса, пола, опыта («Первокурсник», «Любитель», «Опытный стайер», «Гаражный ветеран»);
- Быстрое добавление напитков в один клик (пиво, крафт IPA, водка, коньяк, вино, текила, «Ёрш», настойка);
- Учет закуски (натощак, снеки, стандарт, борщ/сало);
- Расчет чистого этанола ($C_2H_5OH$), пикового промилле по **формуле Видмарка** и времени полного вытрезвления;
- Фиксация фолов (звонок бывшим в 02:30, визит к Ихтиандру, салатный нокаут, потеря ключей).

### 3. 🤖 Полноценный Telegram-бот (`bot.py`)
- Работает прямо в чате Telegram через интерактивные кнопки:
  - Пошаговый выбор снарядов и закуски;
  - Встроенный интерактивный «Детектор Пиздежа» с реакцией на кнопки;
  - Фото-контроль: бот принимает фото пустой тары от пользователя;
  - **Рендеринг корочки на Pillow (PIL):** бот автоматически берет аватарку пользователя из Telegram, вклеивает ее в удостоверение 1200×800 px с гербом, печатью и подписью Наливашкина С.Г., и отправляет готовое фото прямо в чат!

### 4. 🎓 Экзамен ВАК (Теория)
- 10 ситуационных вопросов на знание культуры тостов, этикета и спасения товарищей.

### 5. 🎖️ Генератор официального Удостоверения
- Двухстраничная «корочка» СССР/РФ (1200×800 px) на HTML5 Canvas (в браузере) и Pillow (в боте);
- Золотое тиснение, гербовая синяя печать, защитный QR-код и скачивание в PNG.

## 🚀 Быстрый запуск

### 1. Веб-приложение (Браузер / PWA):
Сервер работает на **чистом Python 3 без сторонних зависимостей**:
```bash
cd projects/litrball-app
python3 app.py 8080
```
Откройте в браузере: **http://localhost:8080**

---

### 2. Запуск Telegram-бота:

В проекте уже настроено виртуальное окружение `venv` с `aiogram`, `pillow` и `python-dotenv`.

1. Получите токен бота в Telegram у [@BotFather](https://t.me/BotFather) через `/newbot`.
2. Запустите скрипт:
   ```bash
   cd projects/litrball-app
   ./start_bot.sh
   ```
   (Скрипт сам спросит токен при первом запуске и сохранит его в `.env`).

Либо укажите токен вручную в файле `.env`:
```env
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
```
И запустите:
```bash
./venv/bin/python bot.py
```

## 📐 Формулы ЕЗСК

- Чистый этанол:
  $$A = \sum \left( V_i \times \frac{ABV_i}{100} \times 0.789 \right)$$
- Промилле по Видмарку:
  $$BAC = \max\left(0, \frac{A}{W \times r} - (T - 0.5) \times 0.15\right)$$
- Спортивный балл:
  $$Score = \left(A \times 0.95 \times \frac{75}{W}\right) \times K_{snack} \times K_{exp} \times K_{pace} - Penalties$$
